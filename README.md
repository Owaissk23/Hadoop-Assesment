# Palmer Penguins – Big Data Pipeline with Hadoop

A Big Data project demonstrating HDFS, Hive, WebHDFS, Pandas, and PySpark using the Palmer Penguins dataset on the Hortonworks HDP Sandbox.

## Project Overview

This project implements a data processing pipeline using the Hadoop ecosystem. It covers distributed data storage, SQL-based querying, Python integration, and distributed data processing.

## Dataset

The project uses the Palmer Penguins dataset, which contains information about penguin species, island locations, bill measurements, flipper length, body mass, and sex.

**Dataset:** [Palmer Penguins CSV](https://raw.githubusercontent.com/allisonhorst/palmerpenguins/main/inst/extdata/penguins.csv)

## Technologies Used

- **Hadoop HDFS:** Distributed data storage
- **Apache Hive:** SQL-based data querying
- **WebHDFS:** HTTP-based access to HDFS
- **Pandas:** Data manipulation and analysis
- **PySpark:** Distributed data processing
- **Hortonworks HDP Sandbox:** Big Data environment

## Project Workflow

1. Load the Palmer Penguins CSV dataset.
2. Store the dataset in Hadoop Distributed File System (HDFS).
3. Create Hive tables and execute SQL queries.
4. Access HDFS data through WebHDFS using Pandas.
5. Process and analyze the dataset using PySpark DataFrames.
6. Explore penguin species, measurements, and other dataset attributes.

## Learning Objectives

- Understand distributed storage using HDFS.
- Perform data analysis using Hive queries.
- Integrate Hadoop with Python and Pandas.
- Access files through the WebHDFS REST API.
- Process structured data using PySpark.
- Build an end-to-end Big Data processing pipeline.

## Environment Setup

- Hortonworks HDP Sandbox
- Apache Hadoop
- Apache Hive
- Apache Spark / PySpark
- Python
- Pandas
- WebHDFS

## Conclusion

This project demonstrates how Hadoop ecosystem tools can be integrated with Python libraries to store, query, access, and process structured data in a Big Data environment.
